# ასტრიდ ლინდგრენის ჯადოსნური კვირეული 📖✨
### ინკლუზიური საგანმანათლებლო ინტერაქტიული ვებ-პორტალი II ა და II ბ კლასებისთვის (7-8 წელი)

ეს ვებ-აპლიკაცია სპეციალურად შექმნილია დაწყებითი კლასების (II ა და II ბ კლასები) მოსწავლეებისთვის „ასტრიდ ლინდგრენის კვირეულის“ ფარგლებში. პლატფორმა სრულად პასუხობს თანამედროვე პედაგოგიურ, ეთიკურ და ინკლუზიურ სტანდარტებს, განსაკუთრებულ ყურადღებას უთმობს ეთნიკური უმცირესობის წარმომადგენელ მოსწავლეებს (რომლებიც ქართულს სწავლობენ, როგორც მეორე ენას) და ტექნიკურად თავსებადია ნებისმიერ ბრაუზერთან, სმარტფონთან, პლანშეტთან და საკლასო სმარტ-დაფასთან.

---

## 🌟 ძირითადი ღირებულებები და პერსონაჟები
1. **პეპი გრძელწინდა (Pippi Longstocking)** — თავისუფალი აზროვნება, გულუხვობა, სიკეთე და სუსტების დაცვა.
2. **სახურავის ბინადარი კარლსონი (Karlsson-on-the-Roof)** — მეგობრობა, მარტოობის დამარცხება, სიხარულის გაზიარება და ფანტაზია.
3. **ემილის თავგადასავალი (Emil of Lönneberga)** — სამართლიანობა, გამბედაობა, გულწრფელობა და სხვებზე ზრუნვა (ალფრედის გადარჩენა).
4. **ყაჩაღის ასული რონია (Ronia, the Robber's Daughter)** — მეგობრობა ბარიერების გარეშე, მშვიდობის არჩევა და ბუნების სიყვარული.

## 🚀 პორტალის 4 ინტერაქტიული სექცია

### 1. 🌟 პერსონაჟების სამყარო (Character World)
* **ინტერაქტიული ბარათები:** 4 გმირის მარტივი და მხიარული ისტორიები.
* **ხმოვანი გახმოვანება (🔊):** ღილაკზე დაჭერით ტექსტი ხმოვანდება, რაც არაქართულენოვან ბავშვებს ეხმარება სიტყვების სწორ წარმოთქმასა და გაგებაში.
* **დაფიქრების კითხვები მეწყვილეებისთვის:** მეგობრული რეფლექსია 7-8 წლის ბავშვებისთვის.
* **საიდუმლო საჩუქრები (🎁):** პეპის ოქროს მონეტა, კარლსონის ტკბილი რჩევა, ემილის ხის კაცუნა და რონიას გაზაფხულის ყვავილი.
* **პატარა ლექსიკონი:** ახალი და საკვანძო სიტყვების მარტივი განმარტებები (სიკეთე, მეგობრობა, სამართლიანობა, გულწრფელი).

### 2. 🎮 ინტერაქტიული ვიქტორინა და თამაშები (Quiz & Value Matching)
* **6 ადაპტირებული შეკითხვა:** ილუსტრირებული და დიდი ღილაკებით აღჭურვილი ტესტი, რომელიც დაფუძნებულია პოზიტიურ წახალისებაზე (არანაირი ნეგატიური შეფასება).
* **მყისიერი აუდიო-ვიზუალური უკუკავშირი:** სწორი პასუხისას ჟღერს მხიარული ზარი (Web Audio API) და ცვივა კონფეტები; არასწორი არჩევანისას ეძლევათ წამახალისებელი მინიშნება („სცადე კიდევ ერთხელ! ❤️“).
* **ვარსკვლავების დაგროვება:** თითოეული სწორი პასუხი აჯილდოებს მოსწავლეს ვარსკვლავით (⭐).
* **მინი-თამაში „დააკავშირე ღირებულება“:** ბავშვები აკავშირებენ გმირებს მათ მთავარ ღირებულებებთან.

### 3. 🎨 შემოქმედებითი და საკომუნიკაციო სახელოსნო (Creative & Communication Corner)
* **„მეგობრობის კამათელი“ (🎲):** წყვილებში სამუშაო ინტერაქტიული გენერატორი. ეხმარება ქართველ და ეთნიკური უმცირესობის მოსწავლეებს შორის ბარიერების მოხსნას (მაგ. „ასწავლეთ ერთმანეთს ერთი სიტყვა თქვენს ენაზე“, „შექმენით მეგობრული მისალმება“).
* **ციფრული სახატავი დაფა (🖌️):** მუშაობს როგორც თითით (სმარტ-დაფასა და პლანშეტზე), ისე მაუსით. მოყვება ნათელი ფერები, ფუნჯის ზომები, სახალისო შტამპები (⭐, ❤️, 🍎, 🎈, 🌸) და ნახატის კომპიუტერში შენახვის ღილაკი (`.png` ფორმატში).
* **„სიკეთის ხე“ (🌳):** ბავშვები ირჩევენ კეთილ სიტყვებს და ისინი ხეზე აყვავდებიან ფერად ფოთლებად.

### 4. 📚 მოგზაურობა საუნივერსიტეტო ბიბლიოთეკაში (Field Trip Preparation)
* **ბიბლიოთეკის ეტიკეტი (4 ოქროს წესი):** ჩუმი ხმა, სუფთა ხელები და ფრთხილი მოპყრობა, მშვიდი ნაბიჯი დარბაზში და სანიშნის გამოყენება.
* **თაროების გზამკვლევი:** როგორ პოულობენ წიგნებს ავტორის ანბანისა და თემების მიხედვით.
* **„წიგნების საგანძურის ძიება“ (ინტერაქტიული ქვესტი):** 6 პუნქტიანი საკონტროლო სია ბიბლიოთეკაში ვიზიტისას.
* **პერსონალური დიპლომის გენერატორი (📜):** ყველა დავალების შესრულების შემდეგ მოსწავლე წერს თავის სახელს, ირჩევს კლასს (II ა ან II ბ) და იღებს საპატიო მკითხველის ულამაზეს დიპლომს, რომლის ამობეჭდვაც (🖨️) შესაძლებელია პირდაპირ ბრაუზერიდან!

## 🛠️ მკაცრი ტექნიკური და ჯვარედინ-ბრაუზერული სტანდარტები
* **კოდირება და ენა:** `<html lang="ka">` და `<meta charset="UTF-8">` — უზრუნველყოფს ქართული უნიკოდის უშეცდომო ჩვენებას.
* **ტიპოგრაფია:** Google Fonts `'Noto Sans Georgian'` სარეზერვო `'Sylfaen', sans-serif` შრიფტებით — ტექსტი არ მახინჯდება არც Windows-ზე, არც iOS/macOS-ზე და არც Android-ზე.
* **ტექნოლოგიები:** სუფთა Semantic HTML5, თანამედროვე CSS3 (Flexbox/Grid, CSS ცვლადები, Print სტილები) და Vanilla JavaScript (ES6+). არ იყენებს მძიმე გარე ბიბლიოთეკებს, რაც უზრუნველყოფს მყისიერ ჩატვირთვას სკოლის შეზღუდულ ინტერნეტ-ქსელებშიც კი.
* **ავტონომიური აუდიო სინთეზი:** ხმოვანი ეფექტები გენერირდება ბრაუზერის `Web Audio API`-ით, რაც გამორიცხავს გარე აუდიო ფაილების დაკარგვას ან ჩატვირთვის პრობლემებს.
* **ხელმისაწვდომობა (WCAG):** კონტრასტული ფერები, დიდი ზომის ტექსტი (მინიმუმ 18px), დიდი ღილაკები პატარა თითებისთვის და „დიდი შრიფტის“ ჩამრთველი საკლასო სმარტ-დაფებისთვის.
* **ბავშვთა უსაფრთხოება და ეთიკა:** არ შეიცავს რეკლამას, ქუქი-ჩანაწერებს (cookies) ან არასრულწლოვანთა მონაცემების შეგროვებას.

## 💻 როგორ გავუშვათ აპლიკაცია?
1. გახსენით პროექტის საქაღალდე.
2. უბრალოდ ორჯერ დააწკაპუნეთ ფაილზე **`index.html`** (ან გახსენით ნებისმიერი ბრაუზერით: Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. აპლიკაცია მზადაა გაკვეთილზე გამოსაყენებლად!
